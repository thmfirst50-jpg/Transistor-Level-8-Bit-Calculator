# Transistor-Level 8-Bit Calculator

A physical 8-bit binary arithmetic calculator made from discrete components, without integrated circuits.

## Goal

Implement arithmetic directly in transistor-level logic and carry signals across a layered circuit.

## Design and implementation

Constructed NAND-based full-adders using 63 BJT transistors and more than 190 resistors across seven stacked prototype-board layers.

## Project highlights

Propagated carry bits between layers to produce results up to 255, displayed as binary output on discrete LEDs.

## Technologies

- BJT transistors
- NAND logic
- Full-adders

## Repository contents

This repository currently contains the project overview. Source code, design files, test data, and project photos have not been uploaded here. The description documents the project; it is not a runnable software release.
